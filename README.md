# advanced_go

> Most of the code and documentation in this repo was generated by [Claude](https://claude.ai).

A collection of advanced Go patterns and use cases, organized by topic.

## Modules

| Directory | Topic |
|---|---|
| [`generics/`](./generics) | Generic types, constraints, and utility functions |
| [`concurrency/`](./concurrency) | Pipeline, fan-out/fan-in, worker pool, errgroup, context propagation |

## Setup

### Initialize the module

```bash
go mod init github.com/davidiwu/advanced_go
go mod tidy
```

### Install / get the module

```bash
go get github.com/davidiwu/advanced_go
```

## Running examples

```bash
# Run the generics examples
cd generics && go run .

# Run the concurrency examples
cd concurrency && go run .
```

## Requirements

- Go 1.19+
