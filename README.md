# advanced_go

A collection of advanced Go patterns and use cases, organized by topic.

Note: Most of the code and documentation in this repo was generated by interacting with [Claude](https://claude.ai).

## Patterns

| Directory | Topic |
|---|---|
| [`generics/`](./generics) | Generic types, constraints, and utility functions |
| [`concurrency/`](./concurrency) | Pipeline, fan-out/fan-in, worker pool, errgroup, context propagation |
| [`behavioral/`](./behavioral) | Functional options, option type, table-driven tests, middleware chaining |
| [`interfaces/`](./interfaces) | Implicit satisfaction, composition, type assertions, segregation, Stringer/error, accept interfaces/return structs |

## Setup

`go.mod` and `go.sum` are already committed. After cloning, just download dependencies:

```bash
go mod download
```

this repo is go-getable. to reference it in your project:

```bash
go get github.com/davidiwu/advanced_go
```

## Running examples

```bash
# Run the generics examples
cd generics && go run .

# Run the concurrency examples
cd concurrency && go run .

# Run the behavioral examples
cd behavioral && go run .

# Run the interface patterns examples
cd interfaces && go run .
```

## Requirements

- Go 1.19+
